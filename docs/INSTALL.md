# TouchMiddle 測試版安裝說明

作者：ilovetai1 · MIT 授權 · 測試包：0.3.0-beta.1 · App：0.3.0／build 5

## 系統需求

此包僅含 Apple Silicon（arm64）版本，供內建觸控板使用。App 宣告最低 macOS 14；實機驗收只有 Apple M5、內建觸控板與 macOS 27.0.1，其他組合尚未確認。Intel 與外接 Magic Trackpad 尚未完成驗證。

安裝包不含個人規則或診斷記錄；每位使用者會建立自己的設定。不需要 Xcode。

## 首次安裝

1. 從作者的 GitHub Releases 下載 `TouchMiddle-0.3.0-beta.1-macos-arm64.zip`，解壓縮後閱讀其中的 `LICENSE`。「Source code」ZIP 僅供自行建置。
2. 將 `TouchMiddle.app` 拖到「應用程式」資料夾（`/Applications` 或 `~/Applications`），不要直接從 ZIP 或暫存位置執行。
3. 雙擊 App。此測試版沒有 Apple Developer ID 簽章或公證，macOS 可能阻擋首次開啟。
4. 若顯示無法驗證開發者，確認來源與檔案可信後，開啟「系統設定 → 隱私權與安全性」，找到 TouchMiddle 的提示，選擇「仍要打開」（Open Anyway），依系統要求確認。此操作只允許這個 App，不需要關閉 Gatekeeper。
5. 若系統明確指出 App 含惡意軟體或檔案受損，停止安裝，不要將它當成一般開發者提示略過。公司管理的 Mac 可能禁止手動允許，需依組織政策處理。
6. 在 App 的「狀態與設定」按「開啟權限設定」，到「隱私權與安全性 → 輔助使用」允許 TouchMiddle。若需要手動加入，選擇剛安裝的 App。返回 App；若仍未取得權限，結束後重新開啟。
7. 在「手勢規則」新增兩指或三指雙擊規則、錄製快捷鍵並儲存。首次預設只有「全域三指輕點 → 中鍵」。
8. 權限、設定與觸控來源正常時，啟動後手勢預設啟用。若啟動時尚未取得權限，授權後手動開啟「啟用手勢」。先碰一下觸控板，再完全放開完成校準。請先在可安全測試的 App 驗證自己的規則。

雙擊是輕點、完全放開、再輕點，不需要壓下觸控板。三指輕點中鍵發生在游標位置；Safari 開連結新分頁時，游標須位於支援中鍵的連結上。

若首次開啟被阻擋，或「輔助使用」開關已開但 App 仍顯示未授權，請閱讀 [SIGNING.md](SIGNING.md)。該說明區分臨時簽章、本機自簽憑證與 Apple 公證，並提供重新加入目前版本授權的步驟。

## 選單列圖示（選用）

在「狀態與設定 → 選單列圖示」切換「在選單列顯示 TouchMiddle 圖示」。預設顯示，選擇會保留到下次啟動。隱藏圖示不會暫停手勢；若關閉設定視窗，可再次開啟安裝位置的 TouchMiddle.app，回到設定並恢復圖示。

## 登入自動啟動（選用）

從固定安裝位置開啟 App，再到「狀態與設定 → 啟動設定」開啟「登入 macOS 時自動啟動 TouchMiddle」。若需要批准，依提示到系統的登入項目設定允許。權限、設定與觸控來源正常時，啟動後手勢預設啟用，仍需完成觸控校準。

此版本的實際登記／取消與重新登入驗收尚未完成；請依 App 與系統顯示的實際狀態判斷，不保證開啟開關即完成所有驗收。

## 更新

1. 在舊版關閉登入自動啟動（若有開啟），並從選單列結束 TouchMiddle。
2. 備份 `~/Library/Application Support/TouchMiddle/rules.json`，保留舊版 App 以便還原。
3. 下載新版並在固定安裝位置替換 App；更新不需要刪除規則檔。
4. 重新開啟並檢查輔助使用權限。ad-hoc 簽章更新可能使舊權限失效，必要時從權限清單移除舊項目再加入新版。
5. 確認規則與實際動作後，再依需要開啟登入自動啟動。

目前沒有自動更新。還原舊版 App 不代表規則檔自動向下相容；需要時一併還原備份。

## 移除

先關閉登入自動啟動，再結束 App，將安裝位置的 `TouchMiddle.app` 移到垃圾桶。可在「輔助使用」清單移除 TouchMiddle。

規則與診斷保留於 `~/Library/Application Support/TouchMiddle/`。只有確定不再需要且已備份時，才自行刪除此資料夾。

# 擴充手勢與觸發組合鍵：開發驗證

日期：2026-10-15（Asia/Taipei）。環境：macOS 27.0.1、arm64。
本次功能尚未公開發布安裝包，App 版本仍為 0.3.0 / build 5。開發建置與後續授權本機安裝的證據分列如下。

## 已實作範圍

原有 5 種手勢保留。新增以下 12 種，合計 17 種。只有使用者建立並啟用對應規則後，才會啟用該手勢；初始規則仍只有三指輕點中鍵。

| 新增手勢 | 辨識條件 |
| --- | --- |
| 一指固定左／右輕點（2 種） | 一指固定至少 150 ms，另一指在它左／右外側輕點，放開操作指時觸發 |
| 兩指固定第三指上／下滑（2 種） | 兩指固定至少 150 ms，第三指垂直位移至少高度 6%，水平位移不超過既有位移上限，在既有單次點按時間內放開操作指 |
| 四指輕點（1 種） | 四指在既有落指時間窗內接觸，滿足最短共同接觸時間，完全放開時觸發 |
| 三指長按（1 種） | 三指共同固定至少 500 ms，第一指接觸後 2 秒內完全放開時觸發 |
| 四角兩指輕點（4 種） | 兩指的起始位置都位於同一角落寬、高各 25% 區域，滿足既有點按條件後完全放開 |
| 兩指固定左／右雙擊（2 種） | 固定兩指，操作指於同側連續完成兩次獨立輕點；第二次開始時間不得超過既有雙擊間隔，兩次位置距離不超過正規化距離 0.10 |

上／下使用正規化座標的 y 增加／減少判定，實體方向仍待觸控板驗收。固定手指移動、離開、更換、接觸取消、無效影格或過大影格間隔，會取消手勢；取消後需全部放開。掌心旗標的取消已用合成影格測試；目前原生 adapter 沒有可靠掌心旗標，不能據此宣稱實體掌心防誤觸已通過。

## 優先順序與等待

- 角落兩指輕點優先於一般兩指雙擊，不另外產生普通雙擊的待定動作。
- 三指長按成功時不產生三指輕點或雙擊。超過普通輕點時間但未達長按條件時，不輸出動作。
- 固定手指的同側單擊與雙擊一起啟用時，單擊等待雙擊間隔結束；第二次有效輕點會改成雙擊，不先送單擊。即使只啟用雙擊也會等待第二次。
- 等待固定手指單擊期間，固定手指仍需保持接觸；固定手指離開會取消待定單擊。左右側待定單擊分別保留。
- 一指與兩指固定規則並用時，先固定一指 150 ms 後加入第二指會進入一指固定操作。兩指固定手勢應讓固定兩指一起落下。
- 沒有攔截 macOS 原生手勢或按鍵，可能同時產生原生動作。

## 組合鍵規則

規則編輯器增加「需按住的按鍵」：⌘、⌥、⌃、⇧，可組成 16 種條件（含不按鍵）。
同一 App 範圍、手勢、組合鍵只能有一條規則。先精確比對組合鍵，再套用既有指定 App 優先、全域其次的規則。
例如只有 ⌥＋四指輕點規則時，⌥⌘＋四指輕點不會匹配。未勾選代表這四種鍵都未按住，不是任意按鍵皆匹配。

實體按鍵狀態取自 HID flags；flagsChanged 與辨識計時器會取消途中換鍵的手勢及待定單擊。
無接觸時保留已完成的觸控校準；接觸途中換鍵則等待全部放開。切換 App 或 PID 仍取消。
觸發組合鍵與輸出快捷鍵各自設定；輸出快捷鍵仍使用錄製的 flags。
沒有新增一般按鍵、滑鼠按鍵或滾輪觸發條件。

新儲存的規則使用 version 2，避免舊 App 忽略新增的按鍵條件。新版可讀 version 1 舊規則，缺少 requiredModifiers 欄位時視為不按鍵；明確的 null 或無效 mask 會報錯。
舊版 App 無法讀取 version 2。若需要降版，先保留舊規則備份；本次沒有改寫已安裝 App 的實際規則檔。
